# Session description
In the world of investment performance analytics, teams are overwhelmed by repetitive ad-hoc data requests each requiring manual SQL, custom calculations, and cross-checking across multiple systems. This session introduces an Agentic Performance Analytics system: a virtual analyst that turns natural language questions like “What’s Fund X’s 3-year return?” into accurate, auditable insights within seconds.

We’ll unpack how this agent uses LLM reasoning, schema-aware SQL generation, and formula APIs to compute institutional-grade performance metrics like Sharpe ratios, returns, and volatility. The talk will walk through its architecture, from intent parsing and secure data retrieval to formula execution, showcasing how conversational intelligence can streamline workflows, ensure consistency, and make analytics accessible to non-technical users.

# Key Takeaways
1. Learn how natural language interfaces can automate end-to-end analytics from query generation to computation.

2. Discover how agentic design and orchestration improve data reliability, speed, and transparency in financial analysis.

# Who Will Benefit
1. Data analysts and BI professionals exploring conversational interfaces for analytics.

2. Data engineers and AI practitioners interested in building agentic systems that bridge LLMs with databases and computation layers.

3. Finance and investment teams looking to accelerate insight delivery and reduce manual query workloads.
